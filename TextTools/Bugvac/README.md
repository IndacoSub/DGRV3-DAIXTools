# TEXTTOOLS - BUGVAC
## Team DAIX, 2026

Bugvac is the TextTools module responsible for **detecting, normalizing, and swapping character names** inside Danganronpa V3 script files.  
It exists because some players *hate* surname‑first naming conventions — and Bugvac fixes that automatically.

This README explains **what Bugvac does**, **how it works**, **its configuration**, and **its internal logic**.

---

## 📌 **Purpose**
Bugvac performs automated name‑swapping inside `.txt` script files.  
It:

1. Loads all known character name pairs (first name + surname).  
2. Detects lines containing those names.  
3. Swaps the order depending on configuration (`DoSwapNames`).  
4. Handles partial/dashed names (e.g., `K-Kaede`, `Sh-Shūichi`).  
5. Writes the corrected lines back to the script files.

It is used after Necronomicon/MarkerStone to ensure script integrity while allowing stylistic name changes.

---

## 📁 **Input Files**
Bugvac processes:

- All `.txt` files inside the `DGRV3/` repo  
- OR only files listed in `different_hashes.txt` (generated by Necronomicon)  
- Depending on the config flag `CheckAllFiles`

It **ignores**:

- README / LICENSE  
- `.git` folders  
- `_sha` / `_lines` files  
- `vars_bak`  
- `Baked` folders  
- Anything not ending in `.txt`

---

## ⚙️ **Configuration System**
Bugvac uses a C# dictionary `ConfigMap` mirroring the C++ TextTools configuration.

### Important Flags
| Flag | Meaning |
|------|---------|
| `DoSwapNames` | Enables name swapping. If false → Bugvac exits immediately. |
| `CheckAllFiles` | If true → scan entire repo. If false → only files in `different_hashes.txt`. |
| `UseIceConvention` | Terminology mode (not directly used by Bugvac). |
| `ReplaceBlacklistedChars` | Switch‑specific character replacement. |
| `DoRemoveSignals` | Removes special markup signals. |
| `DoRandomize` / `SmartRandomization` | Randomization features (unused here). |

Bugvac reads `TextConfig.config` and updates `ConfigMap` accordingly.

`K-Kaito → Mo-Momota`

These allow Bugvac to correctly swap names even when characters stutter or speak with partial fragments.

## 🔍 **Detection Logic**
Bugvac checks each line:

- If the line contains **any known name or surname**,  
- AND does **not** contain `<SIGNAL_NOSWAP>`,  
- THEN swapping is allowed.

It avoids false positives by checking both full names and dash‑names.

---

## 🔄 **Swapping Logic**
Given:

`Kaede Akamatsu`

Bugvac produces:

`Akamatsu Kaede`

It also handles:

- Partial names (`K-Kaede`)
- Mixed fragments (`Sh-Shūichi`)
- Lines containing only one part of the name
- Lines containing both name and surname in reversed order

If both name and surname appear together (e.g., `Kaede Akamatsu`), Bugvac avoids double‑swapping.

---

## 🧠 **Algorithm Overview**
### 1. Load Names  
`SetupNames()` populates `Names` and `DashNames`.

### 2. Load Config  
`SetupConfigMap()` sets defaults.  
`ReadConfig()` loads `TextConfig.config`.

### 3. Determine Files  
`GetFilesToSearch()` returns:

- All `.txt` files  
- OR only files listed in `different_hashes.txt`

### 4. Process Each File  
`ReplaceNames()`:

- Reads file line‑by‑line  
- Detects names  
- Applies `SwapNames()`  
- Writes modified content back

---

## 🛑 **Signals**
Bugvac respects the markup:

`<SIGNAL_NOSWAP>`

Any line containing this tag is **never** modified.

---

## 📤 **Output**
Bugvac rewrites the original `.txt` files in place.

There is **no separate output folder**.

---

## ▶️ **Execution Flow**
Bugvac is normally run by **HiddenDoor**, but can be executed manually.

### Steps:
1. Load names  
2. Load config  
3. Read `TextConfig.config`  
4. If `DoSwapNames = false` → exit  
5. Determine files  
6. Swap names  
7. Save modified files  

---

## 🧷 Limitations
Bugvac does not:

- Modify SPC files

- Modify PB files

- Handle Unicode normalization

- Detect ambiguous names

- Support multi‑language swapping

It is strictly a name‑order correction tool for .txt scripts.

## 🏁 Summary

Bugvac is a lightweight but essential TextTools module that:

- Reads script files

- Detects character names

- Swaps first/surname order

- Handles partial names

- Respects configuration

- Writes corrected files back

It ensures stylistic consistency for players who prefer given‑name‑first formatting.
